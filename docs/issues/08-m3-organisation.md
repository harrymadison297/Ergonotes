- Tags: hierarchical (`a/b`), frontmatter only; rename is a local batch.
- `[[wikilinks]]` by item id, backlinks panel.
- Templates: note with `template: true`, variables `{{date}} {{time}} {{title}} {{cursor}}`; daily note from a template.
- Tasks: checkbox block with optional due/reminder; Tasks view across notes; deleting the block deletes the task.
- Calendar: tasks by due date, notes by created date, daily notes.
- Full-text search over the local index; conflicted non-displayed heads are excluded.
